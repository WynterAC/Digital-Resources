## Reuse and maintenance

- **Check usage rights before reuse.** The font collection contains files from different sources. A nearby license or readme applies only where it clearly identifies the asset; a file being publicly accessible here does not grant permission to redistribute or use it. Keep source and license information with each imported collection.
- **Review scripts and styles before installing them.** They are collected resources and are not all maintained or tested in this repository.
- **Preserve existing paths when adding documentation.** Some names reflect the original imports. Check for links and dependencies before renaming or moving existing assets.

## Contributing

Keep new files in clearly named folders, avoid trailing spaces in new names, and do not commit operating-system metadata such as `.DS_Store`.
